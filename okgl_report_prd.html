活动报表整合 & 后台精简 PRD

本次共 8 处改动：

  1. 活动详情页归到「活动报表」，标题改为活动切换，二维码移到活动切换下方，「最近签到」换成小游戏报表，下方新增抽奖活动报表、受邀会员管理
  2. 删除左侧菜单「小游戏报表」
  3. 活动管理只管理活动，点击活动名称跳到对应活动报表
  4. 受邀会员「关联会员ID」改为 VIP / Companion 单选，新增 VIP/Companion、签到状态筛选和导出按钮
  5. 删除「奖品类别管理」菜单和奖品的类别名称，奖品列表新增活动名称列和活动筛选
  6. 小游戏管理删除排队二维码，已发放数量取员工后台中奖名单，新增活动筛选
  7. 员工后台小游戏取消排队，改为按签到ID添加中奖名单，跟抽奖游戏一样
  8. 抽奖游戏管理新增活动筛选

左侧原型可以直接点，每节下方的按钮会切到对应页面。原型里的数据都是示例。

1活动报表看板（原活动详情页）

位置：左侧菜单「活动报表」，或从「活动管理」点击活动名称进入

a. 页面归属

  1. 原来从「活动管理」点进去的活动详情页，改为属于「活动报表」。进入后左侧菜单高亮「活动报表」，不再高亮「活动管理」。
  2. 删除标题上方的「← 返回」按钮。

b. 活动切换

  1. 标题「Baccarat Series II」改为活动切换器：标题右侧加下拉箭头，点击后展开活动列表。
  2. 列表每项显示：活动名称、活动编号、活动状态、活动时间；顶部有搜索框，可按活动名称或编号搜索。当前活动高亮。
  3. 选中其他活动后，整页切换为该活动的数据：顶部统计卡、小游戏报表、二维码。小游戏报表的筛选条件重置。
  4. 页面 URL 带上活动 ID，刷新或分享链接后仍停留在该活动。

c. 「最近签到」替换为「小游戏报表」

  1. 原「最近签到」模块整块替换为小游戏报表，数据和原「小游戏报表」页一致。
  2. 筛选项：全部小游戏、全部奖品、受邀会员姓名或编号搜索、搜索、重置。删除「全部活动」筛选，数据范围跟随当前选中的活动（切到活动1显示活动1，切到活动2显示活动2）。小游戏、奖品下拉只列出当前活动下的选项。
  3. 列表字段如下，按操作时间倒序，分页 10 / 20 / 50 / 100。
字段说明
ID发放记录 ID
活动名称当前选中的活动
小游戏名称如 EVO - Snakes And Ladder
受邀会员会员编号 · 姓名
奖品名称发放的奖品
操作人员工后台添加中奖名单的员工账号
操作时间YYYY/MM/DD HH:mm:ss

字段和原「小游戏报表」页完全一致，全部保留。

d. 抽奖活动报表、受邀会员管理

  1. 小游戏报表下方新增「抽奖活动报表」，再往下新增「受邀会员管理」。
  2. 两块的列表字段、筛选项、按钮和原页面一致，删除「全部活动」筛选，数据跟随当前选中的活动。

e. 二维码

「查看二维码」移到活动切换（标题和活动编号）下方。

2删除左侧菜单「小游戏报表」

位置：左侧菜单 › 活动管理分组
  1. 删除菜单项「小游戏报表」。原页面的功能已并入活动报表看板（见 1-c）。
  2. 旧页面地址（书签、外链）访问时，重定向到「活动报表」。

3活动管理

位置：左侧菜单「活动管理」
  1. 活动管理只负责活动本身：新增、修改、删除活动和活动 Logo，列表就是活动1、活动2 这些活动。
  2. 点击列表里的活动名称，跳转到「活动报表」对应活动的看板（见 1），左侧菜单同时切到「活动报表」。
  3. 列表字段和其他按钮不变。

4受邀会员：关联会员ID → VIP / Companion

位置：用户管理 › 受邀会员管理（新增 / 修改弹窗、列表）

a. 新增 / 修改弹窗

  1. 删除「关联会员ID（选填，填写已有会员ID）」输入框。
  2. 新增「会员类型」单选，选项 VIP / Companion，两者互斥，只能选一个。必选，默认 VIP。

b. 列表

  1. 删除「关联会员ID」列。
  2. 新增「VIP/Companion」列，放在原「关联会员ID」的位置，每行显示 VIP 或 Companion 标签。
  3. 顶部筛选新增「VIP/Companion」筛选（全部类型 / VIP / Companion）和「签到状态」筛选（全部签到状态 / 已签到 / 未签到），放在「全部活动」右边。

c. 会员编号规则

  1. 会员编号按签到顺序分配：第 1 个签到的会员是 001，第 2 个是 002，依次递增。
  2. 上传名单、新增会员时不分配编号，未签到的会员编号显示「—」；新增弹窗里的会员编号不可填写。
  3. 会员签到成功时分配编号，分配后不再变化。员工后台添加中奖名单时输入的签到ID 就是这个编号。

d. 导出

页面右上角新增「导出」按钮，放在「上传名单」左边，导出受邀会员列表。

e. 历史数据

已填「关联会员ID」的会员标为 Companion，未填的标为 VIP。

5奖品管理

位置：左侧菜单 › 奖品管理分组、奖品管理页
  1. 删除左侧菜单「奖品类别管理」。
  2. 奖品管理新增 / 修改弹窗删除「类别名称」选项。
  3. 奖品管理列表删除「类别名称」列和顶部「全部类别」筛选，只保留编号 / 奖品名称搜索。页面说明文字改为「跨赛事查看奖品，可按编号或奖品名称搜索」。
  4. 已有奖品的类别数据不再展示，不影响奖品本身和已发放记录。
  5. 奖品管理列表新增「活动名称」列，放在 ID 后面。
  6. 奖品管理顶部新增「活动名称」筛选，选项为「全部活动」和各活动。

6小游戏管理

位置：游戏管理 › 小游戏管理
  1. 删除每行操作列的「排队二维码」按钮，操作列只保留「修改」「删除」。
  2. 奖品列的已发放数量 = 员工后台为该小游戏、该奖品添加的中奖名单条数。员工每添加 1 人，已发放 +1，实时更新。
  3. 列表上方新增「活动名称」筛选，选项为「全部活动」和各活动，带搜索、重置按钮。

原型里在员工后台添加一名会员，再切回这里，可以看到已发放数量变化。

7员工后台：排队改为添加中奖名单

位置：员工后台 › Duties › 小游戏（如 Lobby - Smash And Score）

a. 删除排队功能

删除Queue Management、Completed、On-site Registration 三个 Tab，以及排队状态、预估等待时长、Add player to queue、Refresh。

b. 新的页面结构（和抽奖游戏一致）

直接沿用抽奖游戏的中奖名单样式：

  1. 左上：「Prize：」，下方灰字「奖品名称 · Stock left N」。
  2. 右上：「Add Member」按钮。
  3. 下方名单列：No.、Attendee ID、Name。

c. Add Member 弹窗

  1. 点击「Add Member」，弹出「Please input member ID」弹窗，副标题为「员工账号 · 奖品名称」。
  2. 输入框占位文字「Member ID」，员工输入签到ID（即会员编号，如 048）。
  3. 底部按钮：Cancel、Submit。
  4. Submit 后：名单追加一行；Stock left −1；小游戏管理「已发放」+1；活动报表看板的小游戏报表新增一条记录，操作人为当前员工账号。
