账户安全评分

模块：Account Security · 平台：H5 / App / PC · 版本：v1.0 · 2026-11-04

1背景与目标

目前不少用户没有完成安全设置，尤其是资金密码和安全问题，账户被盗风险高，资金类客诉也多。本需求在账户安全页增加满分 100 分的安全评分，分红、黄、绿三个等级，并引导用户逐项完成缺失的设置。

  • 让用户一眼看到自己账户的安全程度。
  • 提升各安全项的完成率。
  • 给出明确的下一步操作，而不只是一个被动的列表。

2评分规则

满分 100 分。共 5 个计分项，每项 20 分。得分 = 已完成项数 × 20。

项目分值完成判定按钮文案（未完成 → 已完成）
Password（登录密码）20已设置登录密码Set Up → Change
Fund Password（资金密码）20已设置资金密码Set Up → Change
Mobile Number（手机号）20已绑定手机号并通过短信验证Bind → Change
Authorization Login（授权登录）20绑定任意一个第三方账号（Google 或 Telegram）即算完成，两个都绑定仍为 20 分Bind → 已绑定图标 + 箭头
Security Question（安全问题）20已设置安全问题及答案Set Up → Change
Password Toggle Settings0不计分仅显示箭头

3等级划分

等级分数区间徽章文案标题文案
红色（低）0 – 59LOWYour account is at risk
黄色（中）60 – 80MEDIUMAlmost there
绿色（高）100HIGHYour account is well protected

等级颜色同时作用于分数圆环、等级徽章、评分卡底色和下方的分段进度条。

4页面结构

  1. 评分卡（顶部）：圆形进度环，中间显示分数（xx / 100），右侧为等级徽章、标题和副标题。
  2. 分段进度条：共 5 段，每段对应一个计分项，已完成的段用当前等级颜色填充。
  3. 下一步引导条：显示第一个未完成的项目和按钮，满分时隐藏。
  4. 设置列表：保持现有顺序和分组。每行左侧增加状态标识：绿色对勾为已完成，空心圆为未完成。

5引导逻辑

  • 副标题文案：
    • 未满分：Complete N more item(s) to reach High.
    • 红色等级时，前面加上：+X pts to reach Medium.
    • 满分：All security items are completed.
  • 未完成的行：显示 +20 标签，原来的文字按钮换成蓝色主按钮（Set Up 或 Bind）。
  • 下一步引导条：按以下优先级取第一个未完成项：Password → Fund Password → Mobile Number → Authorization Login → Security Question。文案示例：Next: Set Up Fund Password +20，点击 Go 进入该项现有的设置流程。

6授权登录

  • 点击该行弹出底部面板，列出 Google 和 Telegram，每项带 Bind 或 Unbind 按钮。
  • 行内为每个已绑定账号显示一个小图标，后跟箭头。
  • 绑定任意一个即得 20 分，绑定第二个不再加分。
